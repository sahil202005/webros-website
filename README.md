# Webros Website

A responsive, single-page website for Webros, a website services startup helping local businesses get online.

## Deploy with GitHub Pages
1. Create a GitHub repository (for example, `webros-website`).
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. After deployment, GitHub will show your public website URL in the Pages settings.

## Before publishing
- Verify the WhatsApp contact number in `index.html` and replace it if needed.
